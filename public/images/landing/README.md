# Landing Page Image Assets

Drop nano-generated images here. Components will automatically use them
when they exist, falling back to gradient placeholders when missing.

## Required Images

### hero/
- `hero-bg.webp` — Full-bleed atmospheric background for the dark hero section
  - Recommended: 1920x1080, dark/moody, cosmic or mystical theme
  - Will be overlaid with opacity ~15%, so high-contrast works best
  - Format: WebP preferred for performance

### systems/
One illustration per wisdom system, used in the features section:
- `dreamspell.webp` — Dreamspell/galactic calendar imagery (260-day cycle, seals)
- `astrology.webp` — Natal chart, zodiac wheel, celestial
- `human-design.webp` — Bodygraph, I'Ching hexagrams, Rave mandala
- `gematria.webp` — Hebrew letters, Tree of Life, numerical patterns
- Recommended: 600x400, can be abstract/artistic
- These appear as card header images

### steps/
Illustrations for the "How It Works" section:
- `step-01.webp` — "Enter birth date" — calendar, date input, cosmic clock
- `step-02.webp` — "All systems calculated" — multiple systems overlay, data visualization
- `step-03.webp` — "Save and track" — profiles, timeline, galactic returns
- Recommended: 400x300, clean and minimal

## Naming Convention
- Use kebab-case filenames
- WebP format preferred (PNG fallback OK)
- Keep file sizes under 200KB each
