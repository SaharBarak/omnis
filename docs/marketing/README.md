Vendored subset (16 of ~50) of coreyhaines31/marketingskills (MIT, LICENSE
in playbooks/) — the launch-relevant set for OmnisX/Starkin. Each folder
is an Agent Skills–spec SKILL.md an AI agent can follow.

programmatic-seo, seo-audit, schema (via seo-aeo-best-practices),
email-marketing-bible.

.claude/skills/ (deliberately not done by the agent — config change).

## Launch sequence (recommended order)

1. **launch** — launch-week plan (Product Hunt/HN/directories cadence).
2. **offers** + **pricing** + **paywalls** — validate the Founding
   Lifetime deal + Explorer/Complete/Practitioner ladder against these
   before launch copy freezes.
3. **signup** + **onboarding** + **cro** — funnel friction pass over
   /login → onboarding → first person (PostHog events land this week).
4. **copywriting** + **product-marketing** — landing message sharpening
   post-rename.
5. **analytics** — instrument what the cro/signup plays need measured.
6. **referrals** + **marketing-loops** — the share loop (public group
   shares revived 533956b) is the native loop; formalize.
7. **emails** + **lead-magnets** — after Resend goes live; the free
   reading is the natural lead magnet.
8. **marketing-plan** + **marketing-ideas** — quarterly frame once the
   above ship.
