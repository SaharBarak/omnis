# For Practitioners

A comprehensive guide for astrologers, Human Design readers, and holistic practitioners who want to use Omnis professionally.

## Overview for Professionals

Omnis isn't just for personal use — it's designed to support your practice with powerful tools for:

- **Batch analysis** of multiple charts
- **Client management** and organization
- **Professional report generation**
- **Streamlined workflows** for readings

> 💼 **Professional features** may require a Pro subscription. Check the pricing page for current plans.

## Batch Analysis Features

### Running Multiple Charts

Instead of generating charts one by one, use batch analysis:

1. Navigate to **Practitioner Tools** → **Batch Analysis**
2. Upload a CSV file with client birth data, or
3. Select multiple people from your existing list
4. Click **"Generate All"**
5. Charts are processed and ready within minutes

![Screenshot placeholder: Batch analysis interface](/images/guides/batch-analysis.png)

### CSV Format for Batch Upload

```csv
name,birth_date,birth_time,birth_location
Sarah Johnson,1990-02-15,15:42,Tel Aviv, Israel
Michael Chen,1985-07-22,09:30,New York, USA
Emma Williams,1992-11-08,23:15,London, UK
```

> 💡 **Tip:** Use ISO date format (YYYY-MM-DD) and 24-hour time for best results.

### Batch Compatibility Reports

Compare one person against many:

1. Go to **Batch Analysis** → **Compatibility Mode**
2. Select your "anchor" person
3. Select multiple people to compare against
4. Generate all compatibility reports at once

**Use cases:**
- Dating clients comparing potential matches
- Teams assessing group dynamics
- Families understanding everyone's interconnections

## Client Management

### Organizing Your Clients

**Creating Client Profiles**

1. Go to **Clients** (different from personal People)
2. Click **"+ Add Client"**
3. Enter their details:
   - Name and contact info
   - Birth data
   - Notes and session history
   - Tags for organization

**Client Profile Fields**

| Field | Purpose |
|-------|---------|
| **Contact Info** | Email, phone for follow-ups |
| **Birth Data** | Their chart foundation |
| **Tags** | Organize by type: "Generators", "Corporate", "Relationship" |
| **Notes** | Session observations, history |
| **Documents** | Attach previous reports |

### Tagging System

Create custom tags to organize clients:

- By HD Type: `Generator`, `Projector`, `Manifestor`, etc.
- By Service: `Natal Reading`, `Year Ahead`, `Compatibility`
- By Status: `Active`, `Follow-up`, `Past`
- By Source: `Instagram`, `Referral`, `Workshop`

![Screenshot placeholder: Client management with tags](/images/guides/client-tags.png)

### Session Tracking

Log each client interaction:

1. Open client profile
2. Click **"+ Add Session"**
3. Record:
   - Date and duration
   - Type of reading
   - Key insights shared
   - Follow-up actions
   - Next session date

## Report Generation

### Available Report Types

**Human Design Reports**
- Full Bodygraph Analysis
- Type, Strategy & Authority Deep-Dive
- Profile and Incarnation Cross
- Centers and Gates Breakdown
- Channel Analysis

**Astrological Reports**
- Natal Chart Interpretation

**Combined Reports**
- Omnis Full Profile (HD + Astrology)
- Relationship Dynamics (combined systems)
- Year Ahead (transits + HD cycles)

### Generating a Report

1. Open client profile or any person's chart
2. Click **"Generate Report"**
3. Select report type
4. Choose customization options:
   - Include/exclude sections
   - Add your branding
   - Set depth level (basic/detailed/comprehensive)
5. Click **"Generate"**
6. Download as PDF or send directly to client

![Screenshot placeholder: Report customization options](/images/guides/report-options.png)

### Branding Your Reports

1. Go to **Settings** → **Practitioner Branding**
2. Upload your logo
3. Set your brand colors
4. Add your contact information
5. Include a personal sign-off message
6. Save template

All generated reports will now include your branding.

### Report Delivery

**Download Options:**
- PDF (print-ready)
- Interactive web link (shareable URL)
- In-app share to client profile

**Email Delivery:**
1. Generate report
2. Click **"Send to Client"**
3. Customize the email message
4. Send directly from Omnis

## Professional Workflows

### Workflow 1: New Client Intake

```
1. Client books session
2. Send intake form (collects birth data)
3. Data imports to Omnis automatically
4. Charts generate in background
5. Before session: Review charts, make notes
6. During session: Use live chart view
7. After session: Generate & send report
8. Log session notes for records
```

### Workflow 2: Group Workshop

```
1. Collect attendee birth data (batch CSV)
2. Run batch chart generation
3. Identify common themes (how many Generators? etc.)
4. During workshop: Reference individual charts
5. After: Send each person their chart + recording
6. Follow up with 1:1 reading offers
```

### Workflow 3: Ongoing Client Relationship

```
Monthly:
1. Check client's upcoming transits
2. Send transit alert email
3. Offer transit reading if significant

Quarterly:
1. Review session history
2. Generate progress report
3. Suggest focus areas

Annually:
1. Generate Year Ahead report
2. Review Solar Return chart
3. Plan year's sessions
```

## Best Practices

### For Readings

1. **Prepare in advance** — Review chart at least 15 min before
2. **Use live view** — Screen share Omnis during virtual sessions
3. **Highlight, don't overwhelm** — Focus on 3-5 key insights per session
4. **Take notes in real-time** — Use the session notes feature
5. **Follow up meaningfully** — Send relevant transit alerts

### For Reports

1. **Customize depth** — New clients need context; returning clients want specifics
2. **Include action items** — What should they DO with this information?
3. **Add personal notes** — Your insights make reports valuable
4. **Quality over quantity** — A focused 5-page report beats a generic 50-page one

### For Your Practice

1. **Batch your admin** — Generate all reports in one session
2. **Use tags religiously** — Future you will thank you
3. **Review client history** — Before every session, check past notes
4. **Track your patterns** — Which services are most popular? Which clients return?

## Frequently Asked Questions

**Q: Can clients access my Omnis account?**
A: No. You can share individual reports via link or PDF, but they can't access your practitioner dashboard.

**Q: Is there a limit to how many clients I can have?**
A: Depends on your plan. Free = 10 people, Pro = unlimited.

**Q: Can I collaborate with other practitioners?**
A: Not yet, but team accounts are on the roadmap!

**Q: How do I handle client data privacy?**
A: Omnis is GDPR-compliant. You can export and delete any client's data at their request. See our Privacy Policy for details.
